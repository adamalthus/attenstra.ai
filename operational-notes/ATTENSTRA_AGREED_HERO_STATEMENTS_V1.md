# Attenstra Agreed Hero Statements V1

## Purpose

Record the currently agreed hero statements for the Attenstra.ai landing page.

## Agreed Hero Statements

1. `In a world of fragmented attention, make every second count.`
2. `Keep what matters moving.`
3. `A new environment for serious work.`
4. `Your tools should work the way you do.`

## Usage Guidance

These statements are the current agreed hero-language set for landing-page and
carousel exploration.

They should be treated as:

- concise
- non-technical
- business-facing
- oriented toward non-technical buyers
- aligned to the current PACE positioning canon without using technical product
  language

## Notes

- Statement 1 is the strongest current anchor line.
- Statement 4 is intended to express the historical breakpoint between users
  adapting to software and software adapting to the work.
