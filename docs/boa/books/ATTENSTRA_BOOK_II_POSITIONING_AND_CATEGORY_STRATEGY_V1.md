# Attenstra Book II Positioning and Category Strategy V1

## Purpose

Define Attenstra's top-level market positioning, category claim, and
competitive frame.

## Current Baseline

The current strongest positioning line is:

- Attenstra is building the environment for serious work.

The current strongest competitive formulation is:

- PACE is not another AI assistant or copilot. It is the environment where
  serious work gets delivered in a world of fragmented attention.

## Category Strategy Questions

This book should eventually establish:

- the category Attenstra is creating or claiming
- how that category differs from assistants, copilots, and coworkers
- who the core buyer is
- what core language should and should not be used publicly
